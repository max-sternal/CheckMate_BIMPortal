## Why CheckMate?

CheckMate prevents planners — and above all reviewers in public authorities — from being put in **"checkmate"** by a flood of model data and LOIN requirements. As an independent, swappable, and safe **Mate (partner)**, CheckMate cleanly separates **deterministic rule checking** (buildingSMART IDS 1.0) from **human judgment supported by AI**.

<CardGrid>
	<Card title="Deterministic Checking (IDS 1.0)" icon="approve-check-circle">
		Checks IFC2X3, IFC4, and IFC4X3 models reproducibly against LOINs, entire AIA projects from the German Federal BIM Portal, or local IDS files — cross-verified against <code>IfcOpenShell</code> / <code>ifctester</code>.
	</Card>
	<Card title="One Core, Three Interfaces" icon="laptop">
		Desktop GUI (JavaFX), headless CLI (with JSON & exit codes), and an MCP server all share the exact same <code>CheckService</code> and identical results.
	</Card>
	<Card title="Open AI & MCP Integration" icon="rocket">
		Connects to Antigravity (target: Nov 2026 MCP App), Claude Desktop/Code, OpenCode, and open models via Ollama (e.g., Mistral Cloud, local Qwen) or Strata — zero vendor lock-in.
	</Card>
	<Card title="Transparent & Open Source" icon="open-book">
		Private open-source project (Apache 2.0) by TU Berlin staff and alumni based on the Sept 2025 BIM Portal Hackathon — with transparent module, version, and contribution records.
	</Card>
</CardGrid>

| Version / Branch | Status | Focus |
|---|---|---|
| **`0.1`** | Frozen | Direct BIM Portal Hackathon snapshot (Sept / Nov 2025) with APSTEX IFC Toolbox |

| **`0.4`** (*CheckMate Lite*) | Work in Progress | Next-gen without Java & APSTEX built on **IFClite** (TypeScript + Rust/WASM, 3D viewer, Antigravity MCP App) |
