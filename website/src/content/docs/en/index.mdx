CheckMate originated at the [2025 BIM Portal Hackathon](https://www.bimdeutschland.de/veranstaltungen/hackathon-2025). This independent project helps check IFC models against information requirements from the [German federal BIM Portal](https://www.bimdeutschland.de/bim-portal) or local IDS files.

<CardGrid>
  <Card title="Open exchange formats" icon="open-book">
    IFC describes the model; buildingSMART IDS describes machine-readable requirements. Local IDS files can be used independently of the BIM Portal.
  </Card>
  <Card title="One check, multiple interfaces" icon="laptop">
    The JavaFX interface, command line and MCP server share the same checking core.
  </Card>
  <Card title="Interpreting results" icon="approve-check-circle">
    CheckMate checks supported IDS requirements. Not every facet is evaluated; professional judgement remains with people.
  </Card>
  <Card title="Open source and dependencies" icon="puzzle">
    CheckMate code is licensed under Apache 2.0. Version 0.3.1 also requires the proprietary APSTEX IFC Toolbox to read IFC files.
  </Card>
</CardGrid>

The [architecture overview](/CheckMate_BIMPortal/en/architecture/overview/) describes the components and dependencies; [IFC and IDS](/CheckMate_BIMPortal/en/architecture/ifc-ids-checking/) explains the checking scope and limitations.
