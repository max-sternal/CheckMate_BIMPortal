## Erste Weiterentwicklung

`0.2` baut auf dem Hackathon-Prototyp auf: Portal-Suche und Start der Oberfläche wurden überarbeitet; ein Brückenmodell wurde mitgeliefert. Eine erste IDS-Prüfung gleicht IFC-Modelle mit LOIN-Anforderungen aus dem BIM-Portal ab. Sie ist sowohl über die JavaFX-Oberfläche als auch über eine Kommandozeile erreichbar.

Der Stand ist eine frühe Prüfung, nicht der volle Funktionsumfang späterer Versionen. Insbesondere sollten heutige MCP-Funktionen und die in `0.3.1` erweiterte Berichterstattung nicht vorausgesetzt werden.

## Start und Grenzen

Die [damalige Anleitung](https://github.com/max-sternal/CheckMate_BIMPortal/blob/v0.2.0/bim-portal/Java_client/hackathon-template/README.md) beschreibt JDK 21, JavaFX und die separat bereitzustellenden APSTEX-JARs. Öffentliche Portal-LOINs können ohne Zugangsdaten abgefragt werden. Die Anleitung und der Code stammen aus dem historischen Stand; externe Dienste und Abhängigkeiten können sich seitdem geändert haben.
